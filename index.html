Profile & Selected Work

Designing clear and engaging digital experiences

Hello, I am Zhenhuan Huang, a fourth-year student at the University of Toronto Mississauga, majoring in Communication, Culture, Information & Technology and Economics. My work explores how web development, interactive media, visual communication, and economic thinking can come together to create useful and engaging experiences.

Selected Projects

Three areas of my academic and creative practice

01

Web Development

Responsive Portfolio Website

A five-page personal portfolio created to present creative work, professional experience, and personal identity in a clear, responsive format. The project uses structured navigation, project cards, modal previews, progress indicators, and layouts adapted for different screens.

HTML CSS Bootstrap

02

Interactive Media

Heartbeat City

An interactive web experience that allows users to explore different city environments through a custom interface. My contribution focused on front-end and UI implementation, including the home screen, city-selection flow, responsive layouts, navigation states, and visual feedback.

HTML CSS JavaScript UI Design

03

Visual Communication

The Price You Don’t See

A visual campaign examining the hidden environmental, waste, and labour costs of fast fashion. I developed the campaign concept and poster system, using semiotic design choices to connect everyday consumer decisions with wider social and economic consequences.

Campaign Design Semiotic Analysis Research
